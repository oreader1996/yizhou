# 桌面翻译栏首版设计

用户在其他软件里阅读或工作时，可以在屏幕右侧查词或翻译句子，查完后继续原来的操作。

## 界面和操作

- 用 Tauri 2、TypeScript 和 Rust，共用一套界面，分别打包给 Windows、macOS 和 Linux。
- 默认显示右侧悬浮按钮。点击展开翻译栏，也可以固定展开，再手动收起。侧栏作为独立窗口，其他软件的窗口尺寸保持原样。
- 参考 Chrome 翻译扩展的窄侧栏布局，采用独立视觉设计。面板从上到下显示翻译方向、原文输入框、翻译按钮和译文区。用户输入或粘贴文字后，点击「翻译」，可以从结果区复制译文。
- Windows 和 macOS 支持右侧贴边置顶。Linux 在窗口环境允许时采用相同操作，Wayland 下可通过应用入口打开普通翻译窗。

## 翻译

- 支持常用单词和完整句子。默认自动识别中文或英文并翻译成另一种语言，同时提供中译英和英译中两个手动选项。自动识别遇到其他语言或不能确定方向时，提示用户手动选择。
- 应用内置 HTTPS 翻译入口，用户安装后即可使用。服务端保存供应商密钥，只在用户触发翻译时接收本次文本。服务端不记录原文或译文，设置长度限制和请求频率限制。网络或服务出错时保留原文，并提示重试。
- 供应商和托管方式在实现计划中选定。选用明确承诺原文和译文不用于训练的接口，并在应用里说明供应商的数据保留期限。发布前需要部署服务、配置供应商凭据，并在安装包中验证默认入口。开发时可用本地测试服务验证请求和错误处理。
- 首版按小范围试用设计。公开发布前由发布方确定服务预算和开放范围。服务达到总调用上限时停止接收新翻译请求，提示稍后重试，并保留用户输入。
- 账号、翻译历史、离线翻译、OCR 和其他语种留到后续版本。

## 验收

- 首版验收环境暂定 Windows 11（x64）、macOS 14 或更新版本（Apple Silicon）和 Ubuntu 24.04 LTS（x64）。在每个环境安装对应的包，打开面板，完成一次中译英和一次英译中，覆盖词语与句子、自动识别与手动选方向。
- 在 Windows 和 macOS 上实际验证按钮贴边置顶、面板展开与收起。Linux 分别验证 X11 和 Wayland 上可用的入口。三个平台都验证输入或粘贴原文后点击翻译，以及复制译文。
- 使用未配置 API Key 的新安装验证在线翻译，并验证网络错误时可以保留文字并重试。
