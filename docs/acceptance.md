# 三端验收

| 环境 | 安装包 | 验收项 |
| --- | --- | --- |
| Windows 11 x64 | NSIS | 右侧浮钮、展开、固定、收起和退出 |
| macOS 14+ Apple Silicon | DMG | 右侧浮钮、展开、固定、收起和退出 |
| Ubuntu 24.04 x64 X11 | DEB | 右侧浮钮、展开、固定、收起和退出 |
| Ubuntu 24.04 x64 Wayland | DEB | 从应用菜单启动普通窗口 |

在各环境用新安装验证 `apple` 和「我今天有空。」自动中英互译，再分别验证手动中译英和英译中、粘贴原文、复制译文及网络恢复后用原文重试。验证时客户端无需配置百度凭据。运行结果和具体系统版本在实际验收后登记。

## 当前构建记录

- Arch Linux x64 上生成了 DEB 调试包。在 GNOME 的 XWayland 下启动了桌面程序，并读取到 48 × 48 的右侧窗口和置顶状态。
- 本地 HTTP 连通性通过百度模拟响应验证。真实百度接口与 Windows、macOS、Ubuntu 安装体验待验收。
